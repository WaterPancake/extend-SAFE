# extend-SAFE

This repository audits SAFE-style multitask failure detection on OpenVLA and
LIBERO. The main result is an evaluation finding: a strong pooled ROC-AUC does
not, by itself, establish timely and calibrated warning on unseen tasks.

Read the GitHub-rendered [technical report](docs/safe_openvla_audit.md), or edit
its [Quarto source](docs/safe_openvla_audit.qmd).

The report links each featured result to its generating script and a compact,
tracked result table under `docs/results_audit/`.
